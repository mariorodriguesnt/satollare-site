# Satollare Pizzaria · Site

Site estático da Satollare Pizzaria (Av. Central, 75, Jardim Piazza di Roma, Sorocaba, SP).
Todos os arquivos ficam na raiz, sem subpastas, para facilitar o envio pelo celular.

- `index.html`: página inicial e página do cardápio
- `estilo.css`: visual
- `site.js`: busca do cardápio e links do WhatsApp
- `cardapio-satollare.pdf`: cardápio para baixar
- `*.jpg` / `*.png`: logo e fotos
